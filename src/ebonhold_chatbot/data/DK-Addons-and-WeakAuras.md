# Death Knight Addons and WeakAuras Guide

## Recommended WeakAuras for Death Knights

### Essential WeakAuras

**Complete Death Knight UI (All Specs)**
- Wago Link: https://wago.io/44gEKqR3f
- Comprehensive UI package for all DK specs (Blood, Frost, Unholy)
- Includes rotation helpers, cooldown tracking, and resource management
- Great starting point for any Death Knight player

**Item and Trinket Tracker**
- Wago Link: https://wago.io/SzufhZ2kd
- Tracks trinket cooldowns and procs
- Shows item effects and durations
- Essential for optimizing burst windows

**Disease Snapshotting WeakAura**
- Wago Link: https://wago.io/diseasesnapshotter
- Tracks disease snapshots for optimal damage
- Shows when your diseases are at peak strength
- Critical for maximizing Unholy DK damage output

**Blood Tap/Plague Leech/Soul Reaper Tracker
- Wago Link: https://wago.io/Zxz7oyMDE/9
- Includes Blood Charge indicator
- Tracks these abilities for DK's
- glows when enough stacks of blood charge and you have a fully depleted rune
Includes Plague Leech indicator
- glows when you have TWO fully depleted runes and both diseases are present on the target
Includes Soul Reaper indicator
- glows when target is under 35% HP and it is not on CD

**Soulstone Active on Dead tracker
- Wago Link: https://wago.io/0ONd9BdZN
- Let's you know if someone has a soulstone on them so you don't waste
- Will show a soulstone icon on people that died (30 seconds, or until any buff is applied after they res / get bres'd).
- This is primarily to prevent wasting combat resses on people that have soulstones.

**Shek'zeer Fixate Warning - for Empress Shek'zeer in Heart of Fear
- Wago Link: https://wago.io/JYX-JFjLv
- Tells you how early you should move from the Set'thik Windblade Fixate during Grand Empress Shek'zeer so you don't get killed as melee.


**MoP Dungeon Automarker
- Wago Link: https://wago.io/wecuTpE5Y
- You now have a group with an aura for each dungeon. They all talk to the same core/settings WA. Select mobs you want to mark in the aura with the dungeon name, and set global settings in the core
Features:
    Marks mobs with unit markers (star, circle, diamond etc.) as soon as you enter combat with them , or if you mouse over them (can be toggled off in custom options).
    Will only mark mobs toggled in custom options. Edit as you please
    By default it marks what i'd consider important mobs.
    It will NOT overwrite/remove existing marks on mobs/players!
    You can also set up custom marking. See FAQ 


## How to Import WeakAuras

1. Install WeakAuras 2 from CurseForge
2. Type `/wa` in game
3. Click "New" → "Import"
4. Go to the Wago.io link above
5. Copy the WeakAura string
6. Paste it in the import window
7. Click "Import"

## Recommended CurseForge Addons

### Essential Addons

**WeakAuras 2**
- Required for the WeakAuras listed above
- Highly customizable UI alerts
- Download from CurseForge

**Method Raid Tools (MRT)**
- MUST HAVE for raiding
- Displays raid timers and mechanics notes
- Works with Kaze MRT timers: https://wago.io/6FbqsGUPm
- Essential for coordinating raid cooldowns and mechanics

**ElvUI**
- Complete UI overhaul
- Customizable action bars, frames, and layouts
- Clean, modern interface
- Highly recommended for a polished UI experience

**Deadly Boss Mods (DBM)** or **BigWigs**
- Boss encounter warnings and timers
- Essential for raiding
- Helps you plan cooldown usage

**Details! Damage Meter**
- Track your DPS performance
- Analyze what abilities do the most damage
- Compare with other players

**Plater Nameplates**
- Better enemy nameplates
- Track diseases on multiple targets
- Helps with multidotting and threat management

## MRT Setup with Kaze Timers

1. Install Method Raid Tools from CurseForge
2. Import Kaze MRT timers from https://wago.io/6FbqsGUPm
3. Join Fojji's Discord (https://discord.gg/fojjiwow) for the latest raid packs
4. Import the raid notes into MRT
5. Type `/rt` in game to access MRT options

## Tips for Using WeakAuras

1. **Start with the Complete DK UI**: The all-spec WeakAura (https://wago.io/44gEKqR3f) is a great foundation
2. **Add the Trinket Tracker**: Helps optimize your burst windows
3. **Install Disease Snapshotting**: Critical for Unholy DK damage optimization
4. **Set up MRT with Kaze timers**: Essential for serious raiding
5. **Customize Positioning**: Move elements to match your UI preferences
6. **Test on Dummies**: Practice with target dummies before raids
7. **Keep Updated**: Check Wago.io regularly for updates
